## 技术要点

- **背景**：`position:fixed` 的渐变层（`.space`）+ 全屏 `<canvas>` 粒子层 + 噪点层，内容层 `z-index:2`。不用 `background-attachment:fixed`（移动端会丢背景）。
- **粒子**：手写 Canvas 2D，无第三方库。
  - 预渲染光点贴图替代逐帧 `shadowBlur`
  - 空间网格分桶做连线，避免 O(n²)
  - 30fps 节流、`requestIdleCallback` 延迟启动、`visibilitychange` 暂停
  - 画布 DPR 自适应（小屏 1x、桌面 1.5x）
  - `prefers-reduced-motion` 时只画一帧静态星图
- **玻璃拟态**：大面积元素（主卡、作品卡）不用 `backdrop-filter`——底下是动画画布，每帧重算模糊代价太高；只保留导航条一条细长模糊。
- **响应式**：1020px 容器，820 / 620 / 520 三个断点；手机端下拉菜单、卡片、按钮均重排。

## 部署

```powershell
# 改完 index.html 后
pwsh -File .\deploy.ps1     # 关键字校验 -> 原子替换上线 -> 公网回读 -> 自动提交推送
```

服务器侧 `/var/www/personal` 是本仓库的克隆，cron 每 2 分钟 `git pull --ff-only`，`deploy.ps1` 里也会立刻触发一次拉取。
