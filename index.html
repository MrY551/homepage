小黄 OFD — 阅读 / 编辑 / 打印

面向银河麒麟与其它 Linux 桌面的 OFD 版式文档工具，按 GB/T 33190-2016 实现。桌面端 Qt、网页端 Canvas、命令行三种形态共用同一个纯 Python 核心库 ofdlite，也只走同一份绘制指令，所以三处显示的版面一致：阅读、改字、A4 拼版打印、转 PDF / PNG / SVG、抽文本、CUPS 直打，另带 deb 打包与 CI 校验。

Xiao Huang — 麒麟 ARM64 Web 环境面板

About

我是小黄，一个代码爱好者。日常写工具和脚本，判断标准只有一条：装完、解压完或者双击一下，它到底能不能直接用。写了多少行、用了多新的框架，不在我的记分牌上。

四件东西各不相同，思路是一样的：组件自带运行时——Web 环境面板把五个组件和它们依赖的库都塞进安装目录，目标机只要有 glibc 就能跑，不碰系统 /etc；一条命令初始化——登记系统的建库、建表、初始账号全在一条 SQL 里；核心逻辑与界面分离——OFD 工具的核心库是纯 Python，桌面端、网页端、命令行共用同一份绘制指令，所以三处显示的内容不会各写一套。剩下那个隐患平台代码还在整理，先把位置留着。
